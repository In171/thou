# Thou

A personal conversational application, developed as an independent project.

Thou brings together everyday conversation, conversation history, and retrieval of personal notes in a simple interface.

## Project status

The application is under active development and private testing. Model integrations are evaluated as the project evolves.

## About this repository

This repository contains only a public project overview. It is not a source-code release or a hosted application.

Private conversations, personal notes, credentials, and deployment details are not included.
